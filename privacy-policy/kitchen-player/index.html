声で動画プレーヤープライバシーポリシー

このページについて

本ページは、SugieTechLab(以下、「当方」)が提供する iPhone・iPad 用アプリ「声で動画プレーヤー」(以下、「本アプリ」)に固有の取り扱いを定めるものです。 ここに記載のない事項は、当方の共通のプライバシーポリシーに従います。

マイクの音声と音声認識

本アプリは、声で動画を操作するためにマイクの音声を聞き取り、端末の中の音声認識(Apple の端末内認識)で文字にします。 音声と聞き取った文字は、当方を含め端末の外へ送らず、保存もしません。命令に使ったら捨てます。

本アプリが扱う情報と保存場所

  • 開いた動画の履歴(動画の番号・題名・開いた日時)
  • お気に入りに入れた動画
  • 動画ごとのパート(開始時刻と名前)
  • 設定(エコー除去の有無、画面のレイアウト、規約に同意した版)
  • 「すべての機能」(App 内課金)の購入状態(Apple が管理します)

これらはお使いの端末の中だけに保存し、当方のサーバーには送りません。アプリを削除すると消えます。機種変更では引き継がれません。 本アプリは、氏名・メールアドレス・位置情報・連絡先などを取得しません。アカウント登録、広告、アクセス解析もありません。

YouTube API Services の利用

本アプリは、動画の再生に YouTube API Services(YouTube の公式の埋め込みプレーヤー)を使います。 埋め込みプレーヤーは、動画を再生するために、端末や利用状況に関する基本的な情報を YouTube(Google)に送ることがあります。 この情報の取り扱いは、Google プライバシーポリシーに従います。 本アプリを使うことで、YouTube 利用規約にも同意したことになります。

古いバージョンの確認

本アプリは、起動したときなどに、当方のサイトから「必要な最低バージョン」を読み込み、古いバージョンをお使いのときに更新をお願いします。 このとき、利用者を特定する情報は送りません。

お問い合わせ

アプリの「設定」→「お問い合わせ」から、メールでご連絡ください。メールの下書きには、調査のためにアプリのバージョン・端末の機種・iOS のバージョン・購入の有無が入ります(送る前に消せます)。
